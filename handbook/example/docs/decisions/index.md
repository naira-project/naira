# Decision log

A decision is a choice that is hard to undo or that people will ask about later. We write it down
with the reasons and the alternatives, in the order we took them. A decision is never rewritten:
a later one replaces it, and says so.

| Number | Title | Status | Date |
|---|---|---|---|
| [0001](/decisions/0001-one-model-gateway) | One gateway for all models | Accepted | 2026-03-12 |

## Add a decision

1. Copy the last page in this folder and give it the next number.
2. Fill in the status, the context, the options and the outcome.
3. Add a row to the table above and a line to the sidebar in `.vitepress/config.mts`.
4. Open a pull request. A decision is accepted when the team lead merges it.

## Statuses

| Status | Meaning |
|---|---|
| Proposed | Open for comment, not binding |
| Accepted | The team works this way |
| Superseded | Replaced by a later decision, which the page links to |
