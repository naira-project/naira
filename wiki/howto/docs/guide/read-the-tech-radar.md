# Read the tech radar

The tech radar tells you which technologies your organisation recommends for new work and which it
does not. An administrator maintains it as a file. Naira shows it; it does not decide anything.

## Open it

Choose **Tech Radar** in the **Explore** group of the sidebar, or the Tech Radar card on the
Overview. The page title is the title the administrator gave the radar.

The radar comes from the `tech-radar` plugin, which is off by default. If the page shows no radar,
ask whoever runs your Naira to turn it on.

## Read the rings

The radar has four quadrants and up to six rings. The rings run from the centre outwards, and the
administrator names them. A radar can use four, for example:

| Ring | Example meaning |
|---|---|
| Adopt | Proven, the default choice for new work |
| Trial | Worth pursuing on projects that can absorb risk |
| Assess | Explore to understand the impact |
| Hold | Do not start new work with this |

Your organisation may use other names and meanings. The ring descriptions come from the radar file.

## Open a quadrant

Click a quadrant to see its entries. Each entry has a ring, an owner and a rationale, which the
administrator writes in the file. An entry that moved shows an indicator: **Moved in since the previous
edition** or **Moved out since the previous edition**. The file also carries an edition label, for
example `2026-09`.

An entry can also show **Catalog matches**: entries in the Naira catalog that match it. Use it to
jump from a technology to what the catalog knows about it.

## Who changes it

Not you, in the portal. The radar file is the only source. To change it, an administrator edits the
file and the plugin picks the change up on its next run. See
[Update the tech radar](/guide/update-the-tech-radar).
